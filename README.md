# AOMI-Graph-Centrality
Projeto AEDS II em Java: Modelagem de microplásticos (AOMI) via Grafo Direcionado Ponderado. Usa Centralidade de Intermediação (JGraphT) para identificar Caminhos Críticos de Fluxo e hotspots de acúmulo em correntes oceânicas. Ênfase na aplicação de Estruturas de Dados complexas.
